CHARTS

charts.exe   Runs straight from this folder. Nothing to install.
setup.exe    Installs Charts with shortcuts and an uninstaller.
             It is a single file: you can copy it to another PC by itself.

Pick one. Each keeps its own data:
  charts.exe   in the "data" folder next to it
  setup.exe    in %LOCALAPPDATA%\Programs\Charts\data
On first install, setup copies the "data" folder sitting next to it.

BACKUP: close Charts and copy the "data" folder.
Uninstalling keeps the "data" folder.

Keep charts.exe in this folder. To have the icon elsewhere, create a shortcut.
